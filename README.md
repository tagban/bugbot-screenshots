# BugBot screenshots

Screenshots people send to **BugBot** (a buddy on VesperNet) along with their bug
reports for [HIM](https://github.com/tagban/him). BugBot files each report as an
issue in [tagban/him](https://github.com/tagban/him/issues) and shows the
screenshots there, from here. They're sorted into year/month folders.

BugBot tells people that reports and screenshots are public before anything is
filed. If one of yours should come down, open an issue in tagban/him.
